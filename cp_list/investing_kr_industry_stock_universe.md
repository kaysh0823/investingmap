# 국내 상장주식 산업별 후보군 — investing-kr.com 업데이트용

- 작성 기준일: 2026-06-27
- 목적: Cursor에 그대로 입력해 산업별 종목 데이터/페이지/태그를 업데이트하기 위한 마크다운 원천 파일
- 범위: KOSPI/KOSDAQ 중심. ETF/ETN/스팩/우선주는 제외. 일부 신규상장·상호변경 종목은 `verify` 표시.
- 중요: 실제 반영 전 KRX/KIND 상장법인목록 및 금융위원회 KRX상장종목정보와 종목코드·상장상태를 마지막으로 대조할 것.

## Cursor 작업 지시문

```text
아래 산업별 종목 테이블을 investing-kr.com의 산업/테마 데이터로 반영하라.
1. 종목코드는 문자열로 저장하고 앞자리 0을 보존한다.
2. 같은 종목이 여러 산업에 등장할 수 있으므로 stock_master는 code 기준으로 deduplicate하고, industry_stock_map은 다대다로 저장한다.
3. level=core는 산업 대표 종목으로 우선 노출하고, level=adjacent는 밸류체인/수혜/인접 종목으로 보조 노출한다.
4. level 또는 code에 verify가 포함된 행은 KRX 현재 상장목록으로 확인 후 반영한다.
5. ETF, ETN, 스팩, 우선주는 제외한다.
6. 사이트 UI에서는 세부 분류(sub_sector)를 필터/칩으로 노출한다.
```

## 누락 방지용 추가 검증 체크리스트

- KRX/KIND에서 기준일 현재 전체 상장법인목록을 내려받아 위 테이블의 종목코드가 모두 존재하는지 확인한다.
- 상호변경·합병·상장폐지 가능성이 큰 바이오/콘텐츠/로봇 중소형주는 종목명보다 종목코드 기준으로 검증한다.
- `조선/조선기자재`는 조선사, 선박엔진, LNG 보냉재, 피팅/밸브, 전장, 블록/단조를 모두 포함했는지 확인한다.
- `에너지/화학`은 정유, 석유화학, 정밀화학, 전력/가스 유틸리티, 원전, 수소, 태양광, 풍력, ESS/배터리소재를 모두 포함했는지 확인한다.
- `K-컬처`는 엔터, 음원, 드라마/영화, 게임, 웹툰/플랫폼, K-뷰티, 패션, K-푸드, 여행/면세로 나눠 누락을 점검한다.
- 신규상장: 2026년 이후 상장된 로봇/바이오/콘텐츠 기업은 코드 부여 방식이 알파뉴메릭일 수 있으므로 KRX 원장과 대조한다.

## 원천/분류 기준 메모

- 공식 상장 여부: KRX/KIND 상장법인목록, 금융위원회 KRX상장종목정보
- 테마 보강: 반도체 장비, 반도체 소재/설계/후공정, 바이오/제약/의료기기, 조선/조선기자재, 방산주, 로봇, 석유화학/태양광/ESS/원전, 엔터테인먼트/영상콘텐츠/게임/음원·음반 등 테마 분류를 교차 참고
- 투자 판단용 파일이 아니라 사이트 데이터 업데이트용 후보군이다.
